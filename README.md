## 2. Descripción del Proyecto y Escenario Asignado
Este proyecto implementa un simulador interactivo por consola basado en la **Situación Problemática 1: Ascenso y Propulsión con el SLS (MRUV y Desprendimiento)** de la misión Artemis. 

---

## 3. Instrucciones de Compilación y Ejecución

El proyecto incluye un **Makefile** para automatizar el proceso de compilación mediante el compilador `gcc`

### Pasos para compilar y ejecutar:

1. Clonar el repositorio y posicionarse en la carpeta raíz:
   ```bash
   git clone [https://github.com/Songalo/Simulador-de-Misiones-Artemis.git](https://github.com/Songalo/Simulador-de-Misiones-Artemis.git)
   cd Simulador-de-Misiones-Artemis
2. Compilar el programa utilizando el Makefile. Para utilizarlo se debe ejecutar:
   ```bash
   make
3. Ejecutar el simulador generado.
   ```bash
   simulador_artemis.exe
4. Si se desea limpiar los archivos compilados se puede utilizar el comando:
   ```bash
   make clean
